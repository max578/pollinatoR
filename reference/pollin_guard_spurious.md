# Guard against the spurious index-versus-yield regression

A common claim regresses a dependence index against absolute yield
across units (e.g. varieties). When the index is the Relative
Interaction Index, `(open - cage) / (open + cage)`, and the yield axis
is the open-arm value, the open term appears on both axes, so a positive
slope is partly guaranteed by construction (Pearson's 1897 spurious
correlation of indices sharing a term). This guard quantifies how much
of the observed slope is mechanical.

## Usage

``` r
pollin_guard_spurious(open, cage, n_perm = 999L, decouple = NULL, seed = NULL)
```

## Arguments

- open:

  Numeric vector of open-arm values, one per unit.

- cage:

  Numeric vector of exclusion-arm values, one per unit.

- n_perm:

  Number of permutations.

- decouple:

  Optional numeric vector (one per unit) giving a yield axis that does
  not share a term with the index.

- seed:

  Optional integer seed.

## Value

An object of class `pollin_spurious`.

## Details

The null is generated by permuting the exclusion-arm values across units
while holding the open-arm values fixed: this destroys any genuine
open-cage relationship but retains the shared-open coupling, so the
permutation distribution of the slope is the slope expected from
coupling alone. A permutation p-value near 1 means the observed slope is
consistent with pure coupling – i.e. spurious. Optionally supply a
decoupled yield axis (e.g. the exclusion-arm yield, or an independent
vigour covariate) on which the index may be regressed without sharing a
term.

## Examples

``` r
set.seed(1)
# independent arms: any index~open slope here is purely mechanical
g <- pollin_guard_spurious(rpois(10, 30), rpois(10, 25),
                           n_perm = 200, seed = 1)
g
#> <pollin_spurious>  index ~ open-yield slope guard
#>   observed slope : 0.0178
#>   coupling null  : mean 0.0169, sd 0.0040 (n_perm = 200)
#>   permutation p  : 0.438  -> slope consistent with mechanical coupling (SPURIOUS risk)
```
