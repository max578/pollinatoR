# Summarise a value

Summarise a value

## Usage

``` r
# S3 method for class 'pollin_value'
summary(object, ...)
```

## Arguments

- object:

  A
  [`pollin_value()`](https://max578.github.io/pollinatoR/reference/pollin_value.md)
  object.

- ...:

  Not used.

## Value

The one-row summary data frame of the value: `channel`, `level`,
`median`, `conf.low`, `conf.high`, `currency`, `year`, `unit`, `basis`,
`population`, `method` and `n`.
