## What this tests

The product D x P x Q per crop-year through `pollin_value(channel = "dependence")` and the
aggregation through `pollin_guard_doublecount()` (32 distinct crops per year, no refusals). It
does not test the estimation of D from trial data (the planted-truth suite does), and P x Q
equals the gross production value by construction, so the price is not independently checked.

## Package behaviour observed

- A dependence ratio from outside a fitted model (a literature class value) has no public entry
  point; the script builds its draws with the internal constructor `.new_pollin_draws()`.
- `pollin_value()` defaults `product` to the response name, so the script sets `product = "crop"`.
- The guard needs at least two values; a one-crop group is valued directly.
